## 测量功能删除修复

### 问题
测量功能产生的点和线段点击"X"删除按钮时，有部分线段未清除。

### 原因
删除逻辑使用闭包变量 `finalLineIndex` 来定位要删除的线条，但当多个测量存在时，删除其中一个后数组索引会发生变化，导致其他测量的删除按钮引用错误的索引。

### 修复方案
1. **线条删除**: 改为直接存储线条引用 `currentMeasurementLine`，删除时使用 `indexOf` 动态查找并移除
2. **标记删除**: 改为使用 `indexOf` 动态查找删除按钮的实际索引，然后基于点数计算需要移除的标记数量，从后往前移除

## 打点属性框再次点击修复

### 问题
打点和定位标记只能第一次点击进入属性框，第二次点击无法进入。

### 原因
使用 `marker.getPopup()` 判断 popup 是否已存在，但 Leaflet 在关闭 popup 后 popup 引用可能处于不一致状态，`setContent()` 后重新打开时 DOM 事件绑定有竞争条件。

### 修复方案
改为每次点击都先 `unbindPopup()` 解绑，再 `bindPopup()` 重新绑定：
```typescript
marker.unbindPopup()
marker.bindPopup(popupContent, {...}).openPopup()
```

- `OnlineMap.tsx` line 1503-1510（打点标记）
- `OnlineMap.tsx` line 839-849（定位标记）

## 测量轨迹删除修复（第二次创建轨迹删除不完整）

### 问题
第一次测量轨迹点击删除按钮可以完全清除，但第二次创建的测量轨迹点击删除按钮有部分轨迹没有清除。

### 原因
删除按钮使用公式 `points.length * 2 + 2` 计算要移除的标记数量，但 `finishMeasurement` 中会 pop 掉最后一个点的距离标签，导致实际标记数量与公式计算不一致：
- 公式计算：n * 2 + 2（n个点，每点2个标记 + totalLabel + deleteButton）
- 实际数量：n + (n-1) + 2 = 2n + 1（最后一个点的label被pop了）
- 差1个，导致删除时会错误地多移除下一个测量的1个标记

### 修复方案
改用标记起始索引追踪：
1. 新增 `measurementMarkerStartIndexRef` 记录每次测量的标记起始位置
2. 删除时根据起始索引精确删除（从 markerStartIndex 到数组末尾）
3. `clearMeasurements` 中同时重置两个起始索引

### 修改文件
- `OnlineMap.tsx` - 新增 measurementMarkerStartIndexRef，重写删除按钮逻辑

## 测量功能双击结束修复

### 问题
激活测量打点功能后，双击鼠标无法结束测量。

### 原因
`handleMapClick`、`finishMeasurement`、`undoLastPoint` 中使用闭包变量 `measurePoints` 而非 `measurePointsRef.current`。双击时：
1. 第一次 click → setMeasurePoints([point1]) → React 异步更新
2. 第二次 click → 闭包中 measurePoints 仍为旧值 [] → updatedPoints = [point2]（丢失 point1！）
3. dblclick → finishMeasurement 闭包中 measurePoints 仍为旧值 → measurePoints.length < 2 → 直接 return

### 修复
1. `handleMapClick`: 从 `measurePointsRef.current` 读取最新点数据
2. `finishMeasurement`: 从 `measurePointsRef.current` 读取最新点数据
3. `undoLastPoint`: 从 `measurePointsRef.current` 读取最新点数据
4. 移除 useCallback 中对 `measurePoints` 的依赖（已改用 ref）
5. 删除 `currentMeasurementMarkers`（未定义变量）
6. 修复 TS 类型错误（iconSize null → undefined as any, 删除按钮事件 e 类型）

### 修改文件
- `OnlineMap.tsx` - handleMapClick/finishMeasurement/undoLastPoint 改用 ref

## 测量轨迹删除修复（第二次删除不完整）

### 问题
第一次点击测量轨迹清除按钮可以完全清除，重新绘制测量轨迹后点击清除按钮没有彻底清除。

### 原因
删除按钮点击事件中，删除线条和标记后**没有重置起始索引**：
- 第一次测量完成后：`markerStartIndex = 0`
- 第一次删除后：标记数组为空，但 `markerStartIndex` 仍然是旧值
- 第二次测量完成后：`markerStartIndex` 被更新为当前数组长度
- 第二次删除时：使用的是**错误的起始索引**，导致删除范围不正确

### 修复
在删除按钮点击事件末尾，重置起始索引为当前数组长度：
```typescript
measurementLineStartIndexRef.current = measurementLinesRef.current.length
measurementMarkerStartIndexRef.current = measurementMarkersRef.current.length
```

- `OnlineMap.tsx` - 删除按钮点击事件中添加起始索引重置
