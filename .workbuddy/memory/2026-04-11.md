## 地图工具图层元素选择工具修复

### 问题描述
用户反馈地图工具中图层元素选择工具（框选、圆形选择、多边形选择）存在以下问题：
1. 选择功能未与地图操作的其他功能互斥，激活选择功能时鼠标操作仍可能触发地图缩放
2. 按Shift键+鼠标选择时选择框没有持久化保留
3. 框选过程中会出现地图放大现象

### 修复内容

#### 1. 修复框选模式下地图缩放问题
**文件**: `frontend/src/renderer/components/Map/OnlineMap.tsx`

在框选模式（point/circle/polygon）激活时，禁用以下地图交互功能：
- `map.dragging.disable()` - 禁用地图拖拽
- `map.doubleClickZoom.disable()` - 禁用双击缩放
- `map.scrollWheelZoom.disable()` - 禁用滚轮缩放

当退出框选模式时，恢复这些交互功能。

#### 2. 修复Shift+框选时选择框不持久化的问题
**文件**: `frontend/src/renderer/components/Map/OnlineMap.tsx`

修改 `handleMouseUp` 函数中的逻辑：
- 非Shift模式下：清除之前的选择框，绘制新的选择框
- Shift模式下：保留之前的选择框，使用 FeatureGroup 管理多个选择框，支持多区域叠加选择
- 移除了在框选完成后立即恢复地图拖拽的代码，确保选择功能完全互斥

### 关键代码变更

```typescript
// 框选模式下禁用所有地图交互
if (isSelectionActive) {
  map.dragging.disable()
  map.doubleClickZoom.disable()
  map.scrollWheelZoom.disable()  // 新增：禁用滚轮缩放
}

// Shift+框选时保留之前的选择框
if (!isMultiSelect && selectionRectRef.current) {
  map.removeLayer(selectionRectRef.current)
  selectionRectRef.current = null
}

// 使用 FeatureGroup 管理多个选择框
if (isMultiSelect && selectionRectRef.current) {
  if (selectionRectRef.current instanceof L.FeatureGroup) {
    selectionRectRef.current.addLayer(newRect)
  } else {
    const featureGroup = L.featureGroup([selectionRectRef.current, newRect])
    selectionRectRef.current = featureGroup as any
  }
}
```

1. 激活框选模式后，尝试滚轮缩放地图 - 应该被阻止
2. 激活框选模式后，尝试双击缩放地图 - 应该被阻止

## 地图工具选择功能后续修复（第四次）

### 问题描述
用户反馈：调整后退出选择功能后仍然没有恢复鼠标左键拖动地图的功能。

### 根因分析
在 `mousedown` 事件处理中（第3360行），`map.dragging.disable()` 被调用来禁用地图拖拽，以便进行框选/圆形/多边形绘制。

但在 `mouseup` 事件处理中，选择操作完成后没有恢复 `map.dragging.enable()`。

之前的代码注释说拖拽状态由 `selectionMode` 变化的 useEffect 控制，但问题是用户完成选择后仍然处于选择模式（selectionMode 未改变），所以不会触发恢复逻辑。

### 修复内容
**文件**: `frontend/src/renderer/components/Map/OnlineMap.tsx`

在 `handleMouseUp` 函数中，当各种选择操作完成后，立即恢复地图拖拽功能：

```typescript
// 1. 点选/框选模式（point mode）完成后
selectionStartPointRef.current = null
pointModeIsDragging.current = false
// 恢复地图拖拽功能（点选/框选操作完成后）
map.dragging.enable()

// 2. 圆形选择模式（circle mode）完成后
selectionDrawingRef.current = false
selectionStartPointRef.current = null
// 恢复地图拖拽功能（圆形选择操作完成后）
map.dragging.enable()

// 3. 多边形选择模式（polygon mode）完成后（在 handleDoubleClick 中）
selectionPointsRef.current = []
// 恢复地图拖拽功能（多边形选择操作完成后）
map.dragging.enable()
```

## 地图工具选择功能后续修复（第五次）

### 问题描述
用户反馈：地图工具中，圆形选择和多边形选择没有调整与鼠标移动地图操作互斥。

### 根因分析
在 `mousedown` 事件处理中：
- 点选模式（point）有 `map.dragging.disable()` 禁用地图拖拽
- 圆形模式（circle）没有禁用地图拖拽
- 多边形模式（polygon）没有禁用地图拖拽

这导致在圆形选择和多边形选择时，用户拖动鼠标会同时移动地图，影响选择体验。

### 修复内容
**文件**: `frontend/src/renderer/components/Map/OnlineMap.tsx`

在圆形选择模式的 `mousedown` 处理中添加禁用地图拖拽：
```typescript
} else if (selectionModeRef.current === 'circle') {
  // 圆形模式：开始绘制
  clearSelectionShape()
  selectionStartPointRef.current = latLng
  selectionDrawingRef.current = true
  // 禁用地图拖拽，避免地图随鼠标移动
  map.dragging.disable()
  setSelectionTip('拖动鼠标绘制圆形，松开完成选择')
  L.DomEvent.stopPropagation(e)
  L.DomEvent.preventDefault(e)
}
```

注意：多边形模式不需要禁用拖拽，因为多边形模式是点击添加点，不是持续拖拽绘制。

### 测试建议
1. 使用圆形选择工具，按住鼠标拖动绘制圆形时，地图不应该跟随移动
2. 圆形选择完成后，鼠标应该可以正常拖动地图

## 地图工具圈选功能修复

### 问题描述
用户反馈装饰图层的圈选功能异常：
1. 矩形选择鼠标松开后无法完成圈选
2. 圆形选择正常
3. 多边形选择双击鼠标无法闭合图形，报错：`polygon.contains is not a function`

### 根因分析
错误发生在 `selectFeaturesInPolygon` 和 `selectFeaturesInRectangle` 函数中：
```typescript
if (markerLatLng && polygon.contains(markerLatLng)) {
```

`polygon.contains()` 不是 Leaflet 的标准方法。Leaflet 的 `L.Polygon` 类没有 `contains` 方法，应该使用 `getBounds().contains()` 来检查点是否在多边形边界框内。

### 修复内容
**文件**: `frontend/src/renderer/components/Map/OnlineMap.tsx`

将两处 `polygon.contains(markerLatLng)` 改为 `polygon.getBounds().contains(markerLatLng)`：

```typescript
// 修复前
if (markerLatLng && polygon.contains(markerLatLng)) {

// 修复后
if (markerLatLng) {
  const isInside = polygon.getBounds().contains(markerLatLng)
  if (isInside) {
```

### 修复位置
1. `selectFeaturesInPolygon` 函数 - 多边形选择时检查抓取坐标点
2. `selectFeaturesInRectangle` 函数 - 矩形选择时检查抓取坐标点
