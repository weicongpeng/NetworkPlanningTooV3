### 工参地图 APP - 性能与交互优化（17:00）

修复了用户提出的 5 个问题：

#### 1. 扇区渲染卡顿优化
- **根因**：每次更新扇区时 `map.remove` 所有旧扇区再逐个 `setMap` 添加新扇区，数据量大时极慢
- **优化措施**：
  - 使用 `AMap.OverlayGroup` 批量管理扇区覆盖物，`clearOverlays` + `addOverlays` 替代逐个操作
  - 添加视野过滤：只渲染当前地图 bounds 内的扇区
  - 添加缩放级别抽稀：低 zoom 时限制最大渲染数量（100~2000 动态阈值）
  - 减少扇区 Polygon 顶点数（16 → 8 steps）
  - 数据对比防重绘：JSON.stringify 对比新旧数据，相同则跳过
  - 根据 zoom 动态调整扇区半径（60m ~ 80m）

#### 2. 点击地图空白处扇区图层消失
- **根因**：高德地图 `map.on('click')` 与 `Polygon.on('click')` 事件冒泡冲突，某些情况下可能触发异常重绘
- **修复**：给所有 Polygon/Circle 的 click 事件添加 `e.stopPropagation()`，阻止事件冒泡到地图

#### 3. 搜索栏布局优化
- **问题**：搜索模式切换按钮（地点/小区/坐标）在最顶端，可能被状态栏遮挡，点击区域太小
- **优化**：
  - `paddingTop` 增加到 48，避开手机状态栏
  - 三个 tab 按钮改为 `flex: 1` 均分宽度，增大点击区域
  - 按钮内边距增大（`paddingVertical: 8`），字体增大到 14px
  - 增加 `zIndex: 100` 和阴影，确保层级最高
  - 清除按钮改为绝对定位在输入框内部右侧

#### 4. 测距交互重构
- **改动**：
  - 删除原来右侧的 MeasureControl 弹窗面板，改为极简浮动提示条
  - 测距中：顶部显示黑色半透明提示条"点击地图添加测距点，双击结束" + 退出/清除按钮
  - 每个测距点旁显示距离标签（段长 + 累积距离）
  - 最后一个测距点旁显示红色圆形"X"删除按钮，点击清除全部测距
  - 双击地图触发 `measureFinish`，显示总距离标签
  - 测距结束时顶部显示总长 + 清除按钮
- **MapView WebView 中**：使用 `AMap.Text` 显示距离标签，自定义 `content` Marker 做 X 按钮

#### 5. 搜索定位点红色小圆点
- 在 mapStore 中新增 `searchMarker` 状态
- 搜索选择结果后，在地图上显示红色圆点标记（带白色边框和阴影，有 drop 动画）
