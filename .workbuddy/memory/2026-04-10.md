# 2026-04-10 工作日志

## 修复：坐标定位悬浮对话框向左漂移 Bug

**文件**：`frontend/src/renderer/pages/MapPage.tsx`

**Bug 根因**：
1. `locationModalPosRef` 是 ref 不是 state，位置更新后不触发重渲染，旧代码用 `setShowLocationModal(false/true)` + `setTimeout(0)` 来强制刷新，这本身不稳定
2. `onMouseMove` 和 `onMouseLeave` 绑定在标题栏小 div 上：鼠标一旦移出该标题栏区域（移到 input 或按钮上），事件停止，导致拖拽中断
3. `style` 中 `left: x || '50%'`，当 x 为数字时没有 `px` 单位，且 x=0 时会错误使用 `'50%'`（0 是 falsy）
4. 因为 `transform: translate(-50%, -50%)` 的存在，每次位置被重置到 50% 时就会向左/上偏移

**修复方案**：
- 将 `locationModalPosRef` 改为 React state `locationModalPos`（类型 `{ x, y } | null`）
- 拖拽时 `onMouseDown` 在标题栏，但 `mousemove/mouseup` 注册到 `document`，松手后清除监听
- `startLeft/startTop` 改为记录弹窗中心点坐标（而非左上角），与 `translate(-50%, -50%)` 对齐
- style 改为三元：有位置时用 `${x}px` 字符串，否则用 `'50%'` 字符串

### 悬停高亮对比度修复
**问题**：按钮在蓝色高亮状态（`bg-blue-400 text-white`）时，悬停效果 `hover:bg-muted` 会让背景变成灰色，与白色文字对比度不足，导致文字看不清。

**修复方案**：将所有高亮按钮的悬停效果从 `hover:bg-muted` 改为 `hover:bg-blue-500`：
- 搜索模式切换按钮（地名搜索/搜索定位）
- 提取坐标（打点）按钮
- 测距按钮
- 地图拖拽按钮
- 圈选按钮

修改后的 className 模式：
```tsx
// 高亮状态
${active ? 'bg-blue-400 text-white hover:bg-blue-500' : 'text-muted-foreground hover:bg-muted hover:text-foreground'}
```
