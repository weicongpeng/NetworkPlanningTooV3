# Requirements

## Project: NetworkPlanningTooV3 (网络规划工具 v3.0)

### Overview

电信网络规划桌面应用，基于 Electron + React + FastAPI 架构，支持地图可视化、邻区规划、PCI规划、TAC规划等功能。

### Current Milestone: 地图工具功能增强

#### Phase 1: 地图定位/抓取控件改造

**需求描述**：

1. **控件标题修改**：将"定位"控件标题改为"位置"
2. **下拉菜单**：在"位置"按钮下添加下拉菜单，包含两个功能：
   - **定位**：保留原有定位功能，输入经纬度跳转至地图位置
   - **抓取**：点击地图任意位置，弹出经纬度信息供用户复制
3. **坐标系纠偏**：抓取的经纬度需要通过坐标纠偏，保证输出的是通用的精确的 WGS84 坐标系经纬度

**技术要点**：
- 地图可能使用 GCJ-02（国测局坐标）或 BD-09（百度坐标），需要转换为 WGS84
- 抓取功能需要监听地图点击事件
- 弹出的经纬度信息需要支持复制操作
